# CloudScale Commerce — Feature & Architecture Roadmap

This document outlines upcoming product and infrastructure milestones.

---

## Phase 11 — Frontend User Interface (Immediate next phase)
- React 19 + TypeScript frontend application.
- Vite build engine.
- Tailwind CSS styling with shadcn/ui components.
- TanStack Query (React Query) for state fetching.
- Zustand for light user session state.
- Storybook component library.

## Future Milestones
- **Multi-Region Active-Active**: Cross-region RDS replication and Route53 latency-based routing.
- **GraphQL Gateway**: Supplement REST endpoints with a federated Apollo GraphQL gateway for frontend data aggregation.
- **AI Recommendation Engine**: Integrate event stream hooks to push product views to an AI recommendation service.
