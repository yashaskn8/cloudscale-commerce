# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 1.0.x | :white_check_mark: |
| < 1.0.0 | :x: |

## Reporting a Vulnerability

We take the security of CloudScale seriously. If you find a security vulnerability, please do NOT open a public GitHub issue. 

Instead, report it via email to **security@cloudscale.io**. 

### What to Include:
1. Detailed steps to reproduce the vulnerability.
2. The impact of the exploit.
3. Any potential mitigations you suggest.

We will acknowledge receipt within 48 hours and provide a fix timeline.
